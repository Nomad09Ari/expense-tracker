# Архитектур

Энэ хуудас долоо хоног бүрт дэлгэрч байдаг. Гацсан үедээ эргэж хараарай — асуудлаа
аль давхаргад байгааг олоход тусална.

---

## Долоо хоног 1 — Зөвхөн хөтөч

```
┌──────────────────────────────────────────┐
│  ХӨТӨЧ                                   │
│                                          │
│   app/page.js                            │
│     ├── useState(expenses)   ← дата энд  │
│     ├── ExpenseForm                      │
│     └── ExpenseList                      │
│           └── ExpenseItem × N            │
│                                          │
└──────────────────────────────────────────┘

Бүх зүйл нэг компьютер дээр, санах ойд.
Refresh → санах ой цоо шинээр эхэлнэ → дата алга.
```

---

## Долоо хоног 2 — Сервер нэмэгдэв (хараахан холбогдоогүй)

```
┌─────────────────────┐          ┌──────────────────────────────┐
│  ХӨТӨЧ              │          │  СЕРВЕР                      │
│                     │          │                              │
│  app/page.js        │          │  app/api/expenses/route.js   │
│    useState(...)    │          │        │                     │
│    ↑                │          │        ↓                     │
│  data/sample.js     │          │  lib/db.js                   │
│  (хуурамч дата)     │          │        │                     │
│                     │          │        ↓                     │
│                     │          │  data/expenses.json          │
└─────────────────────┘          └──────────────────────────────┘
        ╳  Хоёр тал хоорондоо ЯРИАГҮЙ БАЙНА
```

API-г зөвхөн `requests.http` эсвэл хөтчийн хаягийн мөрөөр шалгаж байгаа үе.

## Долоо хоног 3 — Холбогдов

```
┌──────────────────────┐                    ┌────────────────────────────┐
│  ХӨТӨЧ               │                    │  СЕРВЕР                    │
│                      │                    │                            │
│  app/page.js         │                    │  app/api/expenses/route.js │
│    loading / error   │                    │  app/api/expenses/[id]/    │
│    expenses          │                    │        │                   │
│        │             │                    │        ↓                   │
│        ↓             │       HTTP         │  lib/db.js                 │
│  lib/api.js       ───┼───────────────────►│        │                   │
│    getExpenses()     │   GET /api/…       │        ↓                   │
│    createExpense()   │   POST /api/…      │  data/expenses.json        │
│    deleteExpense()   │◄───────────────────┤                            │
│                      │   JSON + status    │                            │
└──────────────────────┘                    └────────────────────────────┘
```

**Давхарга бүр нэг зүйл мэднэ:**

| Давхарга | Юу мэддэг вэ | Юу мэддэггүй вэ |
|---|---|---|
| Компонент | Юу харуулах | Дата хаанаас ирдгийг |
| `lib/api.js` | Яаж асуух (HTTP, JSON) | Дата хэрхэн хадгалагддагийг |
| `route.js` | Юуг зөвшөөрөх, ямар хариу буцаах | Дата ямар форматаар байдгийг |
| `lib/db.js` | Яаж хадгалах, унших | Хэн асууж байгааг |

## Хүсэлтийн бүтэн зам

Хэрэглэгч「追加」товч дархад юу болдог вэ:

```
 1.  ХӨТӨЧ    onSubmit ажиллана, e.preventDefault()
 2.  ХӨТӨЧ    createExpense({ amount, category, note }) дуудагдана
 3.  ХӨТӨЧ    lib/api.js → fetch("/api/expenses", { method: "POST", ... })
 4.  ─────    Хүсэлт сүлжээгээр явна. Хөтөч session cookie-г автоматаар хавсаргана
 5.  СЕРВЕР   Next.js URL-г харж app/api/expenses/route.js-ийн POST функцийг дуудна
 6.  СЕРВЕР   getCurrentUser() → cookie → token → хэрэглэгч. Байхгүй бол 401
 7.  СЕРВЕР   amount, category-г шалгана. Буруу бол 400
 8.  СЕРВЕР   lib/db.js → create({ ...шалгасан талбарууд, userId: user.id })
 9.  СЕРВЕР   Prisma → INSERT INTO expenses …
10.  СЕРВЕР   Response.json(created, { status: 201 })
11.  ─────    Хариу буцаж явна
12.  ХӨТӨЧ    res.ok === true → JSON задарна
13.  ХӨТӨЧ    loadExpenses() → GET /api/expenses (2-11 дахин)
14.  ХӨТӨЧ    setExpenses(шинэ жагсаалт)
15.  ХӨТӨЧ    React дахин зурна → дэлгэц дээр шинэ мөр гарна
```

Ямар нэг зүйл ажиллахгүй бол **аль алхам дээр тасарснаа ол.** Network таб 3-12
дугаарыг харуулна. Терминал 5-10 дугаарыг харуулна. Console 12-15 дугаарыг харуулна.

Асуудлыг олохын оронд бүх кодоо ширтэх нь хамгийн их цаг үрдэг арга. Эхлээд
**хаана тасарснаа** ол, дараа нь тэр газраа л хар.

## Аль давхаргад асуудал байна вэ

| Шинж тэмдэг | Хаанаас эхлэх |
|---|---|
| Дэлгэц дээр юу ч өөрчлөгдөхгүй, Network дээр хүсэлт **алга** | Хөтөч. `onClick` холбогдсон уу? |
| Хүсэлт явсан, `404` ирсэн | URL буруу, эсвэл файлын нэр `route.js` биш |
| Хүсэлт явсан, `400` ирсэн | Илгээсэн датаг хар. Network → Request Payload |
| Хүсэлт явсан, `500` ирсэн | Серверийн код. **Терминалаа хар** — алдаа тэнд бичигдсэн |
| Хариу `200`, гэхдээ дэлгэц хоосон | Ирсэн датаны хэлбэр. Network → Response |
| `data.map is not a function` | Массив ирээгүй. Магадгүй `{ error: … }` ирсэн — `res.ok` шалгаагүй |
| `Promise { <pending> }` харагдана | `await` дутуу |
| Дата ирсэн ч refresh хийхэд алга | Серверт бичигдээгүй. `data/*.json` эсвэл Prisma Studio-г хар |
| Нэвтэрсэн ч дараагийн хүсэлт `401` | Cookie хадгалагдаагүй. DevTools → Application → Cookies. Локал дээр `Secure` туг байвал энэ шалтгаан |
| `Unexpected end of JSON input` | Файлыг бичиж дуусаагүй байхад уншсан. Атомт бичилт хэрэгтэй (week-2) |
