# Толь бичиг

Ойлгохгүй үг таарвал эндээс хараарай. Долоо хоногоор нь бүлэглэсэн.

---

## Ерөнхий

**Frontend** — хэрэглэгчийн харж, дардаг хэсэг. Хөтөч дээр ажиллана.

**Backend** — сервер дээр ажилладаг хэсэг. Дата хадгална, хэн юу хийж болохыг шийднэ.
Хэрэглэгч түүнийг хэзээ ч шууд харахгүй.

**Client** — серверээс юм гуйж байгаа тал. Ихэвчлэн хөтөч, гэхдээ гар утасны апп,
өөр сервер ч байж болно.

**Server** — гуйлтад хариулж байгаа тал. Бас тэр программ ажиллаж байгаа компьютерийг
хэлнэ.

**API** — Application Programming Interface. Нэг программ нөгөөтэйгөө ярих гэрээ.
Энэ төсөлд: "`/api/expenses` руу `GET` илгээвэл зардлын массив буцаана" гэсэн тохиролцоо.

**Deploy** — кодоо интернэт дээр гаргах, бусад хүн хандаж чадахаар болгох.

**Framework** — бэлэн бүтэц, дүрэм өгдөг том сан. Next.js бол framework.

**Library / сан** — тодорхой нэг ажил хийдэг нэмэлт код. `bcryptjs` бол сан.

## React

**Компонент** — JSX буцаадаг функц. Аппын нэг хэсгийг бүрдүүлнэ. Нэр нь **том үсгээр**
эхэлнэ.

**JSX** — JavaScript дотор HTML шиг бичих бичиглэл. `<div className="p-4">Сайн уу</div>`.
`class` биш `className` гэдгийг анзаараарай — `class` нь JavaScript-ийн түлхүүр үг.

**Props** — компонент руу гаднаас дамжуулах өгөгдөл. Функцийн аргумент шиг. Нэг л
чиглэлд урсана: эцгээс хүүхэд рүү.

**State** — компонент цаг хугацааны туршид санаж байх өгөгдөл. Өөрчлөгдөхөд дэлгэц
өөрөө шинэчлэгддэг.

**`useState`** — state үүсгэх hook. `const [utga, setUtga] = useState(anhnii)`.

**`useEffect`** — дэлгэц зурагдсаны дараа ямар нэг зүйл хийх hook. Ихэвчлэн дата татахад.

**Dependency array** — `useEffect`-ийн хоёр дахь аргумент. Хэзээ дахин ажиллахыг заана.
`[]` = зөвхөн нэг удаа.

**Hook** — `use`-ээр эхэлдэг React функцүүд. Зөвхөн компонентийн дээд түвшинд дуудна —
`if` эсвэл давталт дотор дуудаж болохгүй.

**Re-render / дахин зурах** — state өөрчлөгдөхөд React компонентыг дахин ажиллуулж
дэлгэцийг шинэчлэх үйл явц.

**`key`** — жагсаалтын элемент бүрийн хувийн дугаар. React юу өөрчлөгдсөнийг мэдэхэд
хэрэгтэй. Индекс биш, тогтвортой `id` байх ёстой.

**Controlled input** — утга нь state-ээс ирдэг, өөрчлөгдөх бүрт state шинэчлэгддэг
`<input>`. Үнэн нэг газар байх нь давуу тал.

**Derived state** — бусад state-ээс бодогдож гардаг утга (нийт дүн, шүүсэн жагсаалт).
Тусдаа state болгож **хадгалахгүй**, ажиллах үедээ бодно.

## Next.js

**App Router** — Next.js-ийн одоогийн routing систем. `app/` хавтасны бүтэц нь URL-ыг
тодорхойлно.

**`page.js`** — хуудас болдог файл. `app/login/page.js` → `/login`.

**`route.js`** — API цэг болдог файл. Дотроо `GET`, `POST` гэх мэт функц экспортлоно.

**`layout.js`** — доторх бүх хуудсыг ороосон бүрхүүл. Толгой хэсэг, цэс зэрэгт хэрэглэнэ.

**Dynamic route** — хаалттай хавтасны нэр. `app/api/expenses/[id]/route.js` дотор `id`
нь хувьсагч болно.

**`"use client"`** — файлын хамгийн эхэнд бичих мөр. "Энэ компонент хөтөч дээр ажиллана"
гэсэн үг. `useState`, `useEffect`, `onClick` хэрэглэж байгаа бол заавал хэрэгтэй.

**Server Component** — сервер дээр ажилладаг компонент. Next.js-ийн анхдагч байдал.
State, event handler хэрэглэж чадахгүй.

**Hot reload** — файл хадгалахад хөтөч өөрөө шинэчлэгдэх боломж.

**Environment variable / орчны хувьсагч** — кодонд бичихгүй, тусад нь хадгалдаг
тохиргоо (нууц үг, холболтын мөр). `.env` файлд байрлана, git-д **хэзээ ч оруулахгүй**.

## HTTP

**HTTP** — client болон server хоорондын харилцааны дүрэм.

**Request / хүсэлт** — client-с сервер рүү явах мессеж. Method, URL, header,
заримдаа body-той.

**Response / хариу** — серверээс буцах мессеж. Status code, header, ихэвчлэн body-той.

**Method** — ямар төрлийн үйлдэл вэ: `GET` (унших), `POST` (үүсгэх), `PATCH` (өөрчлөх),
`DELETE` (устгах).

**Endpoint** — API-гийн нэг хаяг. `/api/expenses` бол endpoint.

**Header** — хүсэлт/хариуны нэмэлт мэдээлэл. Жишээ: `Content-Type: application/json`
гэдэг нь "body нь JSON байна" гэсэн үг.

**Body** — хүсэлт/хариуны үндсэн агуулга. Ихэвчлэн JSON.

**Status code** — үр дүнг илэрхийлэх 3 оронтой тоо:
- `200` за боллоо · `201` шинээр үүслээ · `204` боллоо, буцаах юм алга
- `400` чиний дата буруу · `401` нэвтрээгүй байна · `403` эрх байхгүй · `404` олдсонгүй
- `500` серверийн код дээр алдаа гарлаа

`4xx` = хүсэлт илгээгчийн алдаа. `5xx` = серверийн алдаа.

**JSON** — дата дамжуулах текст формат. Түлхүүрүүд нь давхар хашилтанд байна.

**`fetch`** — хөтчөөс HTTP хүсэлт илгээх функц. `404`, `500` дээр **алдаа шиддэггүй** —
`res.ok`-г өөрөө шалгах ёстой.

**CORS** — өөр домэйн дээрх сервер рүү хандах эрхийн дүрэм. Энэ төсөлд frontend болон
backend нэг домэйн дээр байгаа тул тааралдахгүй, гэхдээ нэрийг нь мэдэж байвал зүгээр.

## Async

**Synchronous / дараалсан** — мөр бүр өмнөхөө дуустал хүлээнэ.

**Asynchronous / зэрэгцээ** — цаг зарцуулах үйлдлийг хүлээхгүйгээр цааш үргэлжилнэ.

**Promise / амлалт** — "дараа нь үр дүн гарна" гэсэн объект. Файл унших, `fetch` бүгд
Promise буцаана.

**`async`** — функцийг тэмдэглэх түлхүүр үг. Дотор нь `await` бичих боломжтой болно.

**`await`** — "энэ Promise биелтэл хүлээ". `async` функц дотор л бичнэ.

**`try / catch / finally`** — алдаа зохицуулах бүтэц. `try` доторх код унавал `catch`
ажиллана. `finally` нь аль ч тохиолдолд ажиллана.

**Race condition** — хоёр үйлдэл зэрэг явж, аль нь эхэлж дуусахаас хамаараад үр дүн
өөрчлөгдөх нөхцөл. Хоёр хүн нэг файлд зэрэг бичихийг оролдох нь жишээ.

## Дата ба өгөгдлийн сан

**Persistence / хадгалалт** — программ унтарсны дараа ч дата үлдэх шинж.

**Database / өгөгдлийн сан** — дата хадгалах, хайх, олон газраас зэрэг хандах
зориулалттай тусдаа программ.

**Postgres** — өргөн хэрэглэгддэг харилцаат өгөгдлийн сан.

**Table / хүснэгт** — нэг төрлийн датаны цуглуулга. `users`, `expenses`.

**Row / мөр** — хүснэгтийн нэг бичлэг. Нэг зардал.

**Column / багана** — талбар. `amount`, `category`.

**Schema** — датаны бүтцийн тодорхойлолт. Ямар хүснэгт, ямар багана, ямар төрөл.

**Migration** — schema өөрчлөгдөхөд өгөгдлийн санг шинэ бүтэц рүү шилжүүлэх алхам.
Хийсэн өөрчлөлт бүр файл болж үлддэг тул хэн ч ижил бүтцийг сэргээж чадна.

**Relation / холбоос** — хоёр хүснэгтийн хоорондын холбоо. `expenses.userId` нь
`users.id`-г заана.

**Foreign key** — өөр хүснэгтийг заадаг багана. Байхгүй мөр рүү заахаас өгөгдлийн сан
өөрөө сэргийлнэ.

**Index** — хайлтыг хурдасгах бүтэц. Номын арын хэлхээ шиг.

**ORM** — SQL бичихгүйгээр өгөгдлийн сантай ажиллах багаж. Prisma бол ORM.

**Prisma** — энэ төсөлд ашиглах ORM. `schema.prisma` файлд датаныхаа бүтцийг бичнэ.

## Хэрэглэгч ба аюулгүй байдал

**Authentication (нэвтрэлт)** — "чи хэн бэ?" Амжилтгүй бол `401`.

**Authorization (эрх)** — "чи үүнийг хийж болох уу?" Амжилтгүй бол `403`.
Нэвтрэлттэй хольж болохгүй — хоёр тусдаа шалгалт.

**Hash** — буцаагдашгүй хувиргалт. Нууц үг хадгалахад ашиглана. Hash-аас анхны
нууц үгийг гаргаж авах боломжгүй.

**bcrypt** — нууц үг hash хийх зориулалттай алгоритм. Зориуд удаан ажилладаг —
таах гэж оролдоход хэцүү болгодог.

**Salt** — hash хийхээс өмнө нэмэгддэг санамсаргүй утга. Ижил нууц үгтэй хоёр хүн
өөр hash-тай болно. bcrypt үүнийг автоматаар хийдэг.

**Cookie** — сервер хөтөчид өгдөг жижиг өгөгдөл. Хөтөч түүнийг хадгалж, тухайн сайт
руу явуулах хүсэлт бүрт автоматаар хавсаргана.

**`httpOnly`** — cookie-гийн тохиргоо. Хуудсан дээрх JavaScript уншиж чадахгүй болгоно.
Token хулгайлагдахаас сэргийлнэ.

**Session** — нэвтэрсэн хэрэглэгчийн үргэлжлэх төлөв. Энэ төсөлд: token → хэрэглэгч
гэсэн бичлэг.

**Token** — хэрэглэгчийг таних санамсаргүй урт мөр.

## Git

**Repository / repo** — төслийн бүх код, түүх агуулсан хавтас.

**Commit** — өөрчлөлтийн нэг агшны хадгалалт. Тайлбартай.

**Branch / салбар** — үндсэн кодоос салж, тусад нь ажиллах хуулбар.

**`main`** — үндсэн салбар. Ажиллаж байгаа хувилбар энд байна.

**Pull request (PR)** — "миний салбарыг `main` руу нэгтгэе" гэсэн санал. Нэгтгэхээсээ
өмнө өөрчлөлтөө нэг дор харах, ярилцах газар.

**Merge** — салбарыг `main` руу нэгтгэх.

**`git diff`** — юу өөрчлөгдснийг харах тушаал.

**`.gitignore`** — git-д хэзээ ч оруулахгүй файлуудын жагсаалт. `node_modules`,
`.env` заавал энд байна.
